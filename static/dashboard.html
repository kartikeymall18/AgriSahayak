Tools

Find farmer support

Fasal Saathi ranks official scheme and expert-support routes using your crop, location, farming status, request, and latest scan. It prepares a call note for you; it does not submit an application.

Demonstration farm profile

Loads clearly marked sample details for a tomato field. Replace them with real details before using the recommendations for a real farmer.

Add crop, district/state, and the kind of help needed to get a ranked shortlist.

Government agriculture support

Kisan Call Centre

Call 1800-180-1551 for agriculture and allied-sector questions. Ask for help in your preferred language and request referral to the relevant state agriculture specialist if needed.
